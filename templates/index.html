Evidence Tool

Local inventory, duplicate detection, CSV export, and Ollama-assisted categorization.

Local evidence handling note: folder/path scanning reads files from the machine running this Flask app. Ollama categorization sends extracted text and metadata to the configured OLLAMA_ENDPOINTS. Keep the endpoint local or trusted.

Phase 1 — Scan folders or files

Use absolute paths for folders or individual files. Directories are scanned recursively. Directory symlinks are not followed.

Optional: upload selected files/folders into this local app, then scan

Browsers do not expose original absolute folder paths for uploads; files are copied into uploads/ first.
